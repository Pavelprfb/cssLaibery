Your class
b$2$s$red p$16 r$8
The result
A box with a 2px solid red border.
Generated CSS
[class~="b$2$s$red"] {
  border-width: 2px !important;
  border-style: solid !important;
  border-color: red !important;
}

!important is on by default. Opt out with Laibery.config({ important: false }).

The whole syntax

A class is property$value$value. The first segment picks the property; the rest are values, in order.

1 · Parse
Split the token

b$2$s$red → property b, values 2, s, red.

2 · Generate
Turn it into CSS

Numbers become pixels, short values become keywords, and the rule is appended to one stylesheet.

3 · Observe
Keep watching

A MutationObserver picks up new elements and changed classes automatically.

Wins over earlier site CSS

Laibery writes its declarations with !important and keeps its stylesheet after the page's own CSS. A normal rule the site already wrote loses, without editing that stylesheet. A site rule with !important and higher specificity can still win. Opt out with Laibery.config({ important: false }).

Variants

Put a variant before the property, separated by :. Pseudo-classes and breakpoints can be combined.

hover:bg$primary
focus:b$2$s$primary
md:cols$3
md:hover:b$2$s$primary
dark:bg$dark

The dark: variant looks for an ancestor with class="dark".
