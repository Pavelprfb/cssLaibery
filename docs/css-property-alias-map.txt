CSS PROPERTY ALIAS MAP
Source list: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties
Format: alias$VALUE => property: VALUE;
Rule: short aliases use initials; if an alias is ambiguous, the full property name is used.
For multi-part names, initials are joined with hyphens (example: border-top -> b-t).
This is a naming map only; choose a valid CSS value for each property.

Examples:
color$black                 => color: black;
columns$2                   => columns: 2;
background-color$red        => background-color: red;
border-width$1px             => border-width: 1px;
b-t$1px$solid$red             => border-top: 1px solid red;  (only if b-t is unique)
border$1px$solid$blue         => border: 1px solid blue;      (full name if b is ambiguous)

IMPORTANT:
- Replace VALUE with a valid value for the property.
- For shorthand properties, join multi-part values with $ in the class syntax.
- This list does not generate a working CSS parser; it defines suggested alias names.
- Some entries in the source list may be experimental, SVG-related, or browser-dependent.
